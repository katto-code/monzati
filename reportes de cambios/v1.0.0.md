# Monzatti 1.0.0 (código 1)

**Fecha:** 21 de noviembre de 2026 · **Commit:** `660b1c9`

Versión del demo inicial. Este reporte guarda el análisis honesto que se hizo sobre ella y que dio origen a la 1.1.0.

## Estado

- App Android (Kotlin, Jetpack Compose, Hilt, Supabase), espejo 3D web y servidor de fotos con IA.
- 31 pruebas unitarias, todas pasaban.
- Arquitectura por capas limpia, RLS en la base, reserva de inventario con bloqueo y digitalización de prendas real con
  ML Kit.

## Hallazgos del análisis

### Críticos
1. El socio veía el inventario de todas las marcas como si fuera suyo.
2. Las marcas nuevas se llamaban «Tu marca», con categoría «Nuevo» que ningún filtro mostraba.
3. Elegir el rol al iniciar sesión no hacía nada.
4. La sesión no se guardaba: había que entrar cada vez.
5. Registrarse con confirmación de correo dejaba el perfil con id vacío.
6. El dinero se truncaba (107.88 se mostraba como 107).

### Funcionalidad que fingía
- Pestaña «Medidas» falsa (emoji, medidas fijas, talla recomendada = la que elegías).
- Asistente con 3 respuestas fijas; gráfica de ventas inventada; espejo siempre «Conectado».
- Closet sin editar ni borrar; socio sin editar existencias, sin bajas y sin pedidos.
- Fotos del closet subidas a Storage pero nunca descargadas.
- La reserva del pago se renovaba sola y no se liberaba al salir.

### Diseño
- Íconos con emojis y caracteres sueltos; textos de 10–11 sp; formularios llenos con datos de ejemplo.
- Género obligatorio binario; aviso de privacidad mencionado pero inexistente; textos de privacidad incorrectos.
- Botón casi invisible en el estilo Gótica; color de error fuera del tema.

### Seguridad
- Un socio podía marcar su marca como verificada.
- `reserve_variant` abierta: cualquiera podía apartar todo el inventario.
- Espejo con un solo canal público para todos.
- Actualizaciones sin hash se instalaban sin verificar; `allowBackup` activado.
